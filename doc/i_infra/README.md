# i_infra — Infraestrutura, Contêineres e Conectividade

Este diretório concentra especificações de infraestrutura de runtime, tunelamento SSH, empacotamento em contêineres e integração com gateways locais e remotos do **hydra-orch**.

## Conteúdo Planejado

- Topologia de rede e tunelamento SSH reverso para servidores de GPU remota.
- Especificações operacionais do serviço local do gateway OmniRoute (`port 20128`).
- Procedimentos de segurança para bind local e controle de tokens de autenticação.
