# Manuais Operacionais e Guias (doc/b_manual)

Este diretório é reservado para manuais de operação, guias de usuário e instruções de implantação do **hydra-orch**.

## Conteúdo Previsto
- Guia de configuração e autenticação via Chrome DevTools Protocol (CDP) para Claude Pro, ChatGPT Plus e Gemini Pro.
- Manual de configuração de túneis SSH (`autossh`) para nós GPU remotos.
- Instruções de inicialização do servidor FastAPI (`hydra serve`) e integração com agentes Cline e Aider.
