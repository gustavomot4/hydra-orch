# j_manual — Manuais Operacionais e Guias de Usuário (doc/j_manual)

Este diretório concentra manuais de operação, runbooks de manutenção, guias de usuário e procedimentos operacionais do **hydra-orch**.

## Conteúdo Previsto

- Guia de configuração e autenticação via Chrome DevTools Protocol (CDP) para Claude Pro, ChatGPT Plus e Gemini Pro.
- Manual de configuração de túneis SSH (`autossh`) para nós GPU remotos.
- Instruções de inicialização do servidor FastAPI (`hydra serve`) e integração com agentes autônomos (Cline, Aider, Cursor, Codex).
- Procedimentos operacionais para o marco M1 (execução local verificável, revisão de patches e integração).
