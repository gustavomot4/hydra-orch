# d_mer — Modelo Entidade-Relacionamento (MER)

Este diretório concentra a documentação de modelagem lógica, relacionamentos e esquemas de dados relacionais do **hydra-orch** para a persistência transacional em SQLite (`.orchestrator/checkpoints.sqlite`).
