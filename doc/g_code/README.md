# g_code — Arquitetura de Módulos e Código-Fonte

Este diretório concentra documentos de arquitetura detalhada de software, mapas de decomposição de pacotes e diretrizes de engenharia de código do pacote `src/hydra_orch/`.

## Conteúdo Planejado

- Mapeamento de responsabilidades entre camadas (`core`, `engine`, `bridge`, `adapter`).
- Padrões de Design by Contract para serviços internos (`run_service.py`, `git_workspace.py`).
