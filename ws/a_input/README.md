# Entradas do Workspace (ws/a_input)

Este diretório armazena entradas versionáveis utilizadas pelo orquestrador e pelos agentes:
- Briefs de tarefas e contratos de decomposição inicial.
- Esquemas de validação de dados e fixtures estáveis.
- Requisitos externos incorporados formalmente ao projeto.

## Subdiretórios Canônicos

- [`a_standard_requirement/`](a_standard_requirement/): Padrões normativos formais recebidos externamente (padrões de repositórios, contratos e arquitetura).
