# Saídas Locais e Evidências (ws/b_output)

Este diretório reúne saídas de execução geradas pelo hydra-orch e evidências locais de execução de agentes.
As saídas de trabalho são ignoradas pelo Git, com exceção deste `README.md`, do marcador `.gitkeep` e dos arquivos finais explicitamente publicados em [entrega-demo](entrega-demo/README.md). A lista de publicação está no `.gitignore`; temporários, bancos e credenciais permanecem ignorados.
